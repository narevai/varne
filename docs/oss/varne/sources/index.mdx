A source is one connection to a provider. You add sources to a stack on **Integrations** or in `varne.yaml`, then sync them there.

## What a sync does

Syncing a source fetches the last `lookback_days` days (30 by default), stores the provider's raw response, and turns it into rows of cost and usage. A sync also refreshes the source's metadata.

- You can sync as often as you like. For each day, Varne uses the newest sync, so syncing again never counts a day twice.
- Sync a source whenever you want fresh numbers. Varne does not sync on a schedule.
- If a sync fails, **Integrations** shows the provider's error. A failed source does not stop **Sync all** from syncing the others.

## Currency

Costs keep the currency the provider reports, and charts show it in their title. Varne does not convert between currencies. The Docker source always works in USD.

## Keys and permissions

Give Varne keys that can only read costs or analytics where the provider allows it. Store them in environment variables and reference them with `api_token_env`. See [Keep secrets out of the file](/oss/varne/configuration/index#keep-secrets-out-of-the-file).
