A source is one connection to a provider. You add sources to a stack in **Settings** or in `varne.yaml`, then pull them on the **Dashboard**.

## What a pull does

Pulling a source fetches the last `lookback_days` days (30 by default), stores the provider's raw response, and turns it into rows of cost and usage. A pull also refreshes the source's metadata, so you do not run a separate sync.

- You can pull as often as you like. For each day, Varne uses the newest pull, so pulling again never counts a day twice.
- Pull a source whenever you want fresh numbers. Varne does not pull on a schedule.
- If a pull fails, the **Dashboard** shows the provider's error. A failed source does not stop **Pull all** from pulling the others.

## Currency

Costs keep the currency the provider reports, and charts show it in their title. Varne does not convert between currencies. The Docker source always works in USD.

## Keys and permissions

Give Varne keys that can only read costs or analytics where the provider allows it. Store them in environment variables and reference them with `api_token_env`. See [Keep secrets out of the file](/oss/varne/configuration/index#keep-secrets-out-of-the-file).
